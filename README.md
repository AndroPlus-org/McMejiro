# McMejiro

Japanese composite font of Mplus 1 and Roboto.

## Components

Generation script is available at [AndroPlus-org/Scripts-McMejiro](https://github.com/AndroPlus-org/Scripts-McMejiro).

| McMejiro | Mplus 1 | Roboto
|:---:|:---:|:---:|
| **Regular** | Regular | Regular |
| **Thin** | Thin | Thin |
| **Light** | Light | Light |
| **Semibold** | Medium | Medium |
| **Bold** | Bold | Bold |
| **Extrabold** | Black | Black |

Mejiro-20220222 uses **Mplus 1 1.001** and **Roboto 2.137**.

## Variable font

`McMejiro[wght].ttf` is a variable font with a weight axis (`wght` 100–900, default 400), generated from the variable fonts of Mplus 1 (`MPLUS1[wght].ttf`) and Roboto (`Roboto[wdth,wght].ttf`, width fixed at 100) by `mejiro_vf.py`.

| Instance | wght | Mplus 1 | Roboto
|:---:|:---:|:---:|:---:|
| **Thin** | 100 | Thin | Thin |
| **ExtraLight** | 200 | ExtraLight | ExtraLight |
| **Light** | 300 | Light | Light |
| **Regular** | 400 | Regular | Regular |
| **Medium** | 500 | Medium | Medium |
| **SemiBold** | 600 | SemiBold | SemiBold |
| **Bold** | 700 | Bold | Bold |
| **ExtraBold** | 800 | ExtraBold | ExtraBold |
| **Black** | 900 | Black | Black |

Note that the instance names of the variable font follow the standard weight names, so they differ from the static fonts (e.g. static **Semibold** is built from Medium and corresponds to wght 500).
